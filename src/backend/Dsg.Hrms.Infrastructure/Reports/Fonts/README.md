# PDF yazı tipleri

PDF raporlarında Türkçe karakterlerin (ç, ğ, ı, İ, ö, ş, ü) her ortamda doğru çıkması için
yazı tipi uygulamaya gömülür (ADR-0014 §1). Linux konteynerinde sistem yazı tipi yoktur;
SkiaSharp'ın bağımlılıksız yerel paketi yazı tipi çözücü kullanmaz.

| Dosya | Kaynak | Lisans |
|---|---|---|
| `NotoSans-Regular.ttf` | [notofonts/latin-greek-cyrillic](https://github.com/notofonts/latin-greek-cyrillic), `fonts/NotoSans/hinted/ttf` | SIL Open Font License 1.1 (`OFL.txt`) |
| `NotoSans-Bold.ttf` | Aynı | SIL Open Font License 1.1 (`OFL.txt`) |

İndirildiği tarih: 04.11.2026 (#330). OFL, yazı tipinin yazılımla birlikte dağıtılmasına ve
belgeye gömülmesine izin verir; lisans metni yazı tipiyle birlikte tutulur.
